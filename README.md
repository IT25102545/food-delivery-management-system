# Zestro - Food Delivery Management System

Welcome to the **Zestro Food Delivery Management System**! This is a comprehensive, full-stack web application designed to handle online food ordering, customer management, and restaurant administration seamlessly.

## 🚀 Features

- **Customer Portal**: Browse the dynamic menu, add items to the cart, and place orders with a sleek, modern UI.
- **Admin Dashboard**: Manage menu items, view live orders, and monitor restaurant performance in real-time.
- **Rider Interface**: Dedicated login for delivery personnel to track and complete deliveries.
- **Modern Animations**: Scroll-triggered reveal animations and premium loading screens.
- **Dynamic Data**: Fully integrated with a MySQL database for real-time menu and order updates.

## 🛠️ Technology Stack

- **Backend**: Java 17, Spring Boot, JDBC
- **Frontend**: HTML5, Vanilla CSS, TailwindCSS (Admin), JavaScript
- **Database**: MySQL (Aiven Cloud)
- **Build Tool**: Maven

## 📦 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/IT25102545/food-delivery-management-system.git
   ```
2. **Setup Database:**
   Update `DatabaseConnection.java` or `application.properties` with your local MySQL credentials.
3. **Run the Application:**
   Open the project in IntelliJ IDEA and run `FoodDeliveryApplication.java`.
4. **Access the App:**
   Visit `http://localhost:8080` in your browser.
